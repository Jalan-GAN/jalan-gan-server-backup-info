Jalan GAN Server Backup

Alat backup pribadi milik Jalan GAN untuk menyimpan salinan terenkripsi dari file dan arsip aplikasi ke akun Google Drive pemilik.

Aplikasi memakai rclone untuk koneksi resmi Google Drive dan restic untuk enkripsi, snapshot, serta pemulihan versi. Akses Google diberikan oleh pemilik melalui OAuth dan dapat dicabut kapan saja.

Aplikasi ini dipakai oleh pemilik sendiri. Halaman ini hanya menjelaskan fungsi dan kebijakan aplikasi; tidak menyediakan login, akses server, isi backup, atau tautan ke penyimpanan pribadi.
