Kebijakan privasi

Jalan GAN Server Backup adalah aplikasi untuk penggunaan pribadi oleh pemilik akun. Kebijakan ini menjelaskan pengelolaan data Google dan backup oleh aplikasi.

Akses dan tujuan

Dengan persetujuan pemilik, aplikasi memakai izin Google Drive untuk mengunggah, membaca, memeriksa integritas, dan memulihkan repository backup pada folder tujuan yang ditetapkan. Izin OAuth Drive dapat mencakup seluruh Drive, meskipun konfigurasi operasional diarahkan ke folder backup pemilik.

Penyimpanan dan keamanan

Isi file dan metadata snapshot dienkripsi di perangkat pemilik oleh restic sebelum dikirim ke Google Drive. Kredensial OAuth dan kunci pemulihan disimpan terpisah dari folder data yang dibagikan. Kunci diperlukan untuk membaca dan memulihkan backup.

Penggunaan dan pembagian

Data Google digunakan untuk fungsi backup dan pemulihan yang diminta pemilik. Data tidak dijual, tidak digunakan untuk iklan, dan tidak disediakan untuk melatih model AI. Tidak ada akses yang sengaja diberikan kepada pengguna lain. Google Drive memproses penyimpanan sesuai layanan dan kebijakan Google.

Retensi dan penghapusan

Snapshot dipertahankan sampai pemilik menyetujui kebijakan retensi atau penghapusan. Penghapusan file sumber tidak otomatis menghapus snapshot lama. Pemilik mengendalikan penghapusan repository dan pencabutan akses melalui akun Google.

Pencabutan dan kontak

Pemilik dapat mencabut izin aplikasi melalui pengaturan koneksi pihak ketiga akun Google. Pencabutan menghentikan akses berikutnya, tetapi tidak otomatis menghapus backup yang sudah tersimpan. Pertanyaan dapat disampaikan kepada pengelola melalui email dukungan yang tercantum pada layar persetujuan Google.

Halaman informasi ini tidak mengumpulkan data melalui formulir dan tidak memasang analitik atau pelacak. Penyedia hosting dapat mencatat permintaan web sesuai kebijakannya sendiri.

Penggunaan data Google mengikuti Google API Services User Data Policy, termasuk ketentuan Limited Use.
